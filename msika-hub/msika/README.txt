Msika Hub (vanilla HTML/CSS/JS)
Open index.html in a browser. For the JSON files to load from data/, run a local server:
  python3 -m http.server   then visit http://localhost:8000
(If opened by double-click, the site falls back to data/mock-data.js, a copy of the JSON.)
Working: Marketplace (delivery ranges), Mukando, Barter. Mockups: POS & Stock, Adverts.
